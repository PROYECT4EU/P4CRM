# Scripts

This directory will hold controlled import, export, migration and maintenance tooling.

Planned first scripts:

- validate source/import files before ingestion;
- normalise institutional email and URL fields;
- detect duplicate organisations and contact points;
- generate stable P4CRM IDs;
- reconcile suppressions before any campaign audience export;
- export specifically authorised San Blas contacts together with consent references.

Scripts must never silently convert a public/professional contact into a marketing-authorised contact.
